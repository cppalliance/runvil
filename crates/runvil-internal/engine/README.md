# Engine executor

This crate is the Engine's executor: it runs a parsed prompt as a deterministic state machine. Each model round, Pack render, catalog tool call, `store` operation, and timer leaves the executor as an effect for the Harness to perform and answer, and every boundary is reported as an event. Adhoc tool calls, `GetDynamicTools` calls, refused discovery calls, and the store calls a Pack prelude makes while it installs run inside the Engine and are reported only as events, and the run's start probe reads the store directly. Given the same prompt, arguments, and `RunContext` inputs, its seed and start time included, and the same answers, a run produces the same effects and events.
